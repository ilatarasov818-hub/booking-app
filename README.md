# Онлайн-запись к мастеру

Веб-приложение для записи клиентов к мастеру, тренеру, барберу, репетитору.

- **Клиент:** выбирает услугу → дату и свободное время → оставляет имя и телефон → получает подтверждение и файл для календаря.
- **Мастер:** кабинет `/admin` с паролем: предстоящие, прошедшие и отменённые записи, сумма впереди, отмена записи.
- **Уведомления:** новые записи и отмены приходят мастеру в Telegram (необязательно).
- Занятое время сразу пропадает из выбора. Учтены перерыв, выходные и минимальное время до записи.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 22 или новее. На Windows ставится одной командой:

```powershell
winget install OpenJS.NodeJS.LTS
```

Первый запуск (PowerShell):

```powershell
git clone https://github.com/ilatarasov818-hub/booking-app.git
cd booking-app
npm install
copy .env.example .env
npm start
```

Откройте:
- http://localhost:3000 — страница записи для клиентов;
- http://localhost:3000/admin — кабинет мастера (пароль из `.env`, по умолчанию `demo`).

Обновление: `git pull`, затем `npm install` и `npm start`.

Для разработки: `npm run dev`. Страница откроется на http://localhost:5173 и сама обновляется при правках.

## Настройка под мастера

Всё в файле `config.json`:

| Поле | Что это |
|---|---|
| `name`, `master`, `tagline`, `address`, `phone` | Название, мастер, описание, адрес, телефон |
| `accent` | Фирменный цвет кнопок, например `#0a84ff` |
| `timezone` | Часовой пояс мастера, например `Europe/Moscow` |
| `hours` | Часы работы по дням; `null` — выходной |
| `breaks` | Перерывы каждый день |
| `slotStep` | Шаг времени в минутах (30 → 10:00, 10:30, …) |
| `horizonDays` | На сколько дней вперёд можно записаться |
| `minLeadMinutes` | За сколько минут минимум до начала можно записаться |
| `services` | Услуги: `id`, название, описание, длительность в минутах, цена |

После правки перезапустите `npm start`.

## Уведомления в Telegram

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Впишите его в `.env`: `TELEGRAM_BOT_TOKEN=...` и перезапустите сайт.
3. Напишите своему новому боту `/start`.
4. В кабинете `/admin` нажмите «Подключить». Бот пришлёт подтверждение.

## Где хранятся данные

Записи хранятся в папке `data/` (файлы JSON). Для переноса или резервной копии скопируйте эту папку.
